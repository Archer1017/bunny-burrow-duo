# 兔洞双人组

结合平台跳跃与机关协作的双人闯关游戏。

本仓库保存经过脱敏的源码快照，属于开发原型。

## 功能

- 单人挑战和双人合作模式，各二十关。
- 宝石、钥匙、出口、双色池和倒计时机关门。
- 移动、跳跃和关卡布局的多轮调整。

## 运行

在本目录运行 `python3 -m http.server 8000`，浏览器访问本地页面，按页面说明操作。

## 当前范围

已有HTML、样式和脚本原型。

- 完整关卡和机关流程仍需回归游玩。

## 验证

JavaScript 语法检查通过；完整关卡尚未逐一游玩。
